# QCOFA Offline Skin v1.0.0
让你在 QuestCraft 上的离线账号也可以使用皮肤。

## 📖 简介

QCOFA Offline Skin 是一个 Minecraft Fabric 模组，由 QCOFA 额外模组提供。它让你在 QuestCraft 上的离线账号也可以使用皮肤在暂停菜单中添加「QCOFA 更换皮肤」按钮，支持本地皮肤更换
